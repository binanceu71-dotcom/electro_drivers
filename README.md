# Electrodrivers SaaS Portal ⚡

Закрытый корпоративный SaaS-портал для управления базой знаний, онбордингом сотрудников и CRM отчетов из Telegram-бота.

---

## ⚙️ Основные модули и функционал

### 1. Авторизация и безопасность (Auth & Security)
- Стартовый экран — всегда защищенная форма входа и подачи заявок (`/auth`).
- 3 уровня доступа:
  - `User`: чтение Базы знаний, прохождение онбординга.
  - `Admin`: полный CRUD в Базе знаний + доступ к CRM отчетов сотрудников.
  - `SuperAdmin`: полный доступ, модерация новых регистраций, назначение ролей (`User` ↔ `Admin`), блокировка аккаунтов, журнал аудита.
- Модерация новых пользователей: регистрация создает аккаунт со статусом `pending`. Вход блокируется до одобрения в панели `SuperAdmin`.

### 2. CRM отчетов сотрудников (Telegram Bot Webhook)
- **Доступ:** Только для ролей `Admin` и `SuperAdmin` (пользователи `User` не имеют доступа).
- **Вебхук для приема отчетов:** `POST /api/crm/webhook`
- **Функционал CRM:**
  - Прием и автоматический парсинг JSON отчетов от Telegram-бота.
  - Журнал отчетов со статусами: `pending_review` (на проверке), `approved` (одобрен), `rejected` (отклонен), `needs_clarification` (требует уточнения).
  - Карточка отчета с метриками (отработанные часы, пробег км, зарядка кВт·ч, госномер авто), текстом и фотоотчетами.
  - Встроенный эмулятор для тестирования отправки JSON-пакетов ботом.

#### Пример JSON-пакета для вебхука Telegram-бота:
```json
{
  "telegram_user_id": "7829104",
  "telegram_username": "@driver_sergey",
  "employee_name": "Сергей Николаев",
  "report_type": "shift_report",
  "shift_date": "2026-08-30",
  "title": "Отчет по смене #42",
  "metrics": {
    "hours_worked": 8.0,
    "mileage_km": 210.5,
    "kwh_charged": 42.0,
    "vehicle_plate": "Е777КХ 799"

  "photo_url": "https://example.com/photo.jpg"
}
```

### 3. База Знаний (Wiki / Документация)
- Пространства (Spaces) ➔ Разделы ➔ Статьи (Articles).
- Расширенный Markdown/WYSIWYG редактор:
  - **Кликабельные ссылки в тексте:** `[Текст ссылки](https://...)`
  - **Фото и GIF:** `![Описание](https://...)`
  - **Видеоматериалы:** `[video: https://...](Подпись)`
  - **Быстрая панель эмодзи:** ⚡ 🔋 🚗 🔌 📋 ⚠️ 🚨 💡 📌 🔧 💬 🚀 💻 📊 🛡️ ✅ ❌ ⏱️
  - Заголовки H2/H3, списки, интерактивные чек-листы (`- [x]`, `- [ ]`), таблицы, блоки кода и цитаты.
- Полнотекстовый поиск (`⌘K` / `Ctrl+K`), экспорт в Markdown (`.md`) и печать.

### 4. Дизайн и Темы (Monochrome Minimalism)
- Строгая минималистичная монохромная гамма:
  - **Темная тема:** Глубокий черный фон (`#050505`), белый и серый текст, чистый контраст.
  - **Светлая тема:** Чистый светлый фон (`#fafafa`), темный текст, нейтральные серые границы.
- Интерактивный StarCanvas на Canvas API (`requestAnimationFrame`), адаптированный под обе темы.
